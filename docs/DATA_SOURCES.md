# Data-source policy

Evaluate API-Football, football-data.org, Open-Meteo, official club/league sites, openfootball datasets and reputable RSS feeds before enabling them. Verify current terms, quotas, coverage, endpoint access, attribution and update cadence; these can change. Cache responses, record fetched_at UTC, published_at where available, provider, source URL, fixture IDs and raw-response hash. Do not bypass terms or commit secrets.
